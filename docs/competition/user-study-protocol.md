# 用户研究协议（待真实采集）

本文件是待执行的研究协议，不是用户研究结果。当前仓库没有真实用户试用数据，不得据此声称满意度、SUS 或路线完成率。

## 研究目标

验证游客是否能理解系统的场景状态、路线时间轴、证据来源和不可行提示，并比较普通问答与约束路线规划在任务完成上的差异。

## 参与者与伦理

- 目标：景区游客或有景区出行经验的成年人。
- 记录匿名 participant ID，不记录身份证、联系方式或未经同意的影像。
- 参与者在开始前阅读说明并自愿同意；可随时退出。
- 研究者不得暗示正确答案，也不得把模拟路线数据描述为实时官方导航。

## 任务

1. 查询一个景点事实并指出证据来源。
2. 输入“带老人、剩余三小时、想看 14:00 演艺”的路线约束。
3. 输入一个无法满足的轮椅/时间组合，判断系统是否明确拒绝。
4. 修改当前时间或已游览景点，观察路线是否随约束变化。
5. 复述推荐路线的到达、停留、演艺和结束时间。

## 测量

每个任务记录：

- 是否完成任务；
- 首次完成时间；
- 是否需要研究者提示；
- 是否误解路线或证据；
- 对回答可信度和可执行性的 1–5 分评价；
- API latency、trace 状态和是否使用 fallback（由系统日志记录）。

研究完成后可计算任务成功率、平均完成时间、错误类型和 95% 置信区间。样本量、分组和统计方法必须在采集前冻结。

## 问卷与访谈

- 可选 SUS：按标准 10 项量表和标准计分方法执行。
- 访谈：最信任哪一部分？是否理解 estimated 标记？不可行提示是否有帮助？哪一步让你犹豫？如果只能改一处，改什么？
