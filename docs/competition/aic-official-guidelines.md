## 第一部分：官方赛题规则与评分标准（原文收录）

### 一、赛题说明
鼓励参赛团队敏锐捕捉社会及行业需求、技术趋势与产业痛点，结合大模型、智能体等前沿技术和人工智能软硬件产品，探索人工智能+新应用、新服务、新业态、新模式，打造具有颠覆性、社会效益或商业潜力的场景化解决方案。

### 二、作品范围参考
包括但不限于：作品应用行业和领域不限。建议围绕“人工智能+”科技、产业、消费、民生、治理等重点领域，选取某一细分赛道或细分场景，提交具有实际应用价值的场景解决方案。场景不分大小，重点关注**场景创新性、技术适配性与应用落地性**。

### 三、作品要求（6项刚性要求）
1. **聚焦场景创新核心**：明确场景的新颖性，详细说明场景挖掘的背景、用户痛点及未被满足的需求，避免重复已有成熟应用场景。
2. **技术赋能场景深度融合**：方案需深度融合人工智能技术或软硬件产品，技术或产品选型需与场景需求高度适配，体现“技术赋能场景”的核心逻辑，避免技术与场景脱节。
3. **完整技术方案交付**：提交材料需包含完整的技术方案，包括场景需求分析报告、创新场景定义说明、AI技术/产品实施方案、功能演示视频或原型、效果验证数据，跨专业组队需说明成员分工与协作机制。
4. **突出差异化优势**：需突出场景创新点与差异化优势，包括场景挖掘的独特性、技术应用的创新性、用户体验的优化性，对比同类场景或传统解决方案的核心差异。
5. **落地可行性与商业潜力**：方案需具备落地可行性，需说明实施条件、资源需求、推广路径，鼓励结合具体行业资源或试点场景提供落地证明，体现社会效益或商业潜力。
6. **合规与伦理规范**：作品需符合国家法律法规与行业伦理规范，涉及用户隐私、公共安全等场景的需提供合规说明，数据使用需合法合规，尊重场景相关方权益。

## 第三部分：后续优化与代码/文档迭代准则（四项红线）

后续所有对本项目（代码、报告、论文、PPT）的修改，必须严格遵守以下四项红线准则：

1. **红线一 · 证据绝对可复现（针对“测试与验证” 10分）**：
   - 严禁为了“好看”而人为编造平滑数据。消融实验必须严格采用 `docs/ablation_report.md` 中的 7 组真实测量值；
   - 事实问答权威基线必须明确为 50 题 **96.0%**（48/50），消融实验明确为受控运行观察值 **98.0%**，场景槽位测试 **100% (40/40)**，边界路线测试 **100% (60/60，0次物理硬违规)**。
2. **红线二 · 架构表述与代码严格一致（针对“解决方案可行性” 20分）**：
   - 检索机制必须严格表述为代码实测的：基于 `Promise.all` 的三路并行检索（向量 + 结构化 + 关键词）+ RRF 融合（$k=60$）+ Cross-Encoder 重排 + 官方指南权威兜底；
   - 严禁将 2026-09-16 的历史串行回退链当成当前系统表述，但在评委防守环节可作为“技术演进与重构”亮点进行抗辩。
3. **红线三 · 拒绝虚假承诺，坚守物理真实（针对“需求分析与应用效果” 30分）**：
   - 路线推荐必须基于 23 景点与 31 道路数字孪生路网的真实物理米数、坡度阻抗与演出时间窗；
   - 必须保留“诚实拒绝与优雅降级”特性：当时间不足时，系统必须明确拒绝并给出备选微游览，绝不能为了“讨好游客”而生成不可行的超时路线。
4. **红线四 · 突出工程交付与极低成本 ROI（针对“项目实施与总结展望” 20分）**：
   - 避免讲成纯云端调用或纯算法公式，必须强化端到端交付实力（双屏 UI 原型、证据追溯抽屉、高德实景导航调起）；
   - 商业化强调“4 核边缘节点支撑 200 QPS 拓扑求解、年综合成本 < 1.5 万、3~6 个月收回成本”的轻量落地优势。
