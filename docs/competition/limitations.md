# 已知限制与下一阶段

## 当前限制

1. `data/route` 中部分步行时间和设施属性是 estimated，需要现场采集、运营方确认和版本化。
2. 当前评测主要验证检索命中、事实覆盖、场景抽取和路线硬约束；尚未证明真实游客满意度或路线偏好。
3. 路线评测验证景点覆盖、时间、连通性和行动能力约束，但不等于真实道路导航、拥堵预测或无障碍设施实时可用性。
4. Full-RAG 结果显示 Structured-only 在当前 Gold 上优于 fused；融合与 Rerank 仍需要更具代表性的长尾问题验证。
5. 前端 lint 当前有既有 `80 errors / 3 warnings`，不影响已通过的 TypeScript/Vite build，但应作为独立质量债务处理。

## 下一阶段建议

- 与景区运营方核验路线边、步行时间、无障碍设施和演艺时刻表。
- 扩充包含口语、别名、错别字、模糊指代和多约束请求的 Gold 集。
- 增加真实用户任务测试，分别衡量事实正确率、路线可执行率、拒答正确率和完成时间。
- 在不改变正式评测口径的前提下，继续分析融合和 Rerank 对长尾查询的收益。
