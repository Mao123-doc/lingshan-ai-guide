# 当前参赛版本说明

更新：2026-10-15。用户已指定 `lingxiaochan10-06.pptx` 和《项目方案2.0.pdf》为功能目标，覆盖2026-10-03的精简范围。完整状态、代码映射及尚需证据的差异见[功能对齐台账](competition/feature-contract.md)。

游客入口为 `/`、`/qa`、`/recommend`。问答包含实际检索证据、流式生成、数字人、浏览器语音、识景、定位附近和回答评分。路线支持默认返回出口、完整时间预算、到场缓冲、进度更新、登记坐标动线与外部地图跳转。生产环境首次在线缓存后提供离线应急；离线模式不声称提供实时演出、视觉或问答模型。

后台入口为 `/admin/login`、`/admin/knowledge`、`/admin/dashboard`、`/admin/digital-human`、`/admin/reports`，均由服务端JWT保护数据接口。运营数据来自持久化记录，空数据不编造满意度。WebSocket仅向认证后台发送事件。

主服务8010，向量服务8002。浏览器承担识别和播报，不启动8001。视觉模型需另配置 `VISION_BASE_URL`、`VISION_MODEL`、`VISION_API_KEY`，未配置时明确不可用。GPS、相机、录音与Service Worker需要受支持浏览器和权限，跨设备语音可能不同。

资料原件、历史录屏与历史评测不重写。PPT的17页与旧文档14页、重排机制及物理实测口径冲突在台账中列出，不以恢复UI掩盖。新工程发布不等于历史精确指标已经复测。
