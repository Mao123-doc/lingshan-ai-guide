# 核心版本说明

生效日期：2026-10-03。用户确认将项目收敛为“可信问答 + 可行路线规划”，后台仅承担知识维护。本说明记录当前代码范围；历史竞赛素材不作为当前功能的证据。

## 当前入口

| 地址 | 功能 |
| --- | --- |
| `/` | 两个功能入口、四个常见问题、知识库入口 |
| `/qa` | 文字问答、连续追问、清空并新建会话、回答依据抽屉 |
| `/recommend` | 自然语言或表单规划、关键条件追问、时间及无障碍约束、不可行解释、外部地图导航 |
| `/admin/login` | 管理员登录 |
| `/admin/knowledge` | 知识上传、列表、删除、索引重建、结构化检索检查 |

问答使用 JSON 请求一次返回答案和真实检索证据，不触发音频、数字人配置或图片识别请求。依据抽屉显示来源、片段、相关度和响应耗时；相关度不等于准确率。模型不可用时显示“知识库摘录”，不冒充模型生成。清空对话会更换会话 ID，后续问答不继续旧历史。

路线引擎、三路并行检索与 RRF、状态抽取门禁、数据契约及原始评测资产继续保留。`/visitor/recommend` 仅作为旧客户端兼容适配器，游客端统一使用 `/visitor/route/plan`。`/visitor/qa` 保留 SSE 兼容分支；当前界面使用包含证据的 JSON 响应。

## 已移除

- Live2D / PixiJS 数字人、情绪动画、自动播报、语音输入、图片识别、评分交互。
- 宣传长页、景点卡片墙、GPS 周边景点与设施搜索。
- 运营看板、情感报告、数字人配置、对话导出、访客统计、WebSocket 广播。
- 对应前端页面/组件、后台接口、Python TTS/ASR 服务、闲置模型资源和依赖。

下线的游客端接口包括 `/tts`、`/vision/recognize`、`/feedback`、`/conversation-feedback`、`/hot-questions`、`/spots`、`/nearby`、`/nearby-facilities`、`/dh-config`；这些路径的前缀为 `/api/v1/visitor`。后台仅保留 `/api/v1/admin/knowledge/*`。旧入口返回 404；已移除页面由前端回到首页。

保留 `conversations.json` 作为核心问答审计记录，不再生成反馈、访客画像或日报统计文件。现有历史业务数据没有删除。

## 运行与验证

启动方式见根目录 README。默认启动 Express 主服务（8010）及向量服务（8002），无需 8001 语音服务。前端按页面加载代码，知识库页面不会在打开首页时一起加载。

本次本地验证（2026-10-03）：

- 前后端生产构建、前端 lint、`git diff --check` 通过。
- 前端单元测试 18 项、后端 API/认证/隔离测试 27 项、Python 工具测试 70 项通过。
- 桌面/手机浏览器用例 24 项通过；浏览器 API 使用固定响应。Windows 下测试服务退出等待较长，关闭本次启动的 Vite 进程后测试以退出码 0 结束。
- `backend/src/services/**/*.test.ts` 全部通过，其中场景基准 40/40、路线基准 60/60、硬违规 0；三路融合、RAG Trace、重排解析、LLM 身份及门禁测试通过。
- 另以隔离 DATA_ROOT 和真实 Express 后端验证了生产前端的首页、问答依据、可行路线、登录、知识上传及 390px 手机布局。文本模型被禁用、向量服务使用测试替身，该检查验证应用连接与降级路径，不代表在线模型效果。
- 闲置展示资源删除 9,785,145 字节；直接依赖声明减少 13 项，本地依赖树移除 150 个包。按页加载后最大单个 JS 文件约 351 KB（压缩前），首页仍需加载共享组件代码，不能将该数字当作首页总下载量。

在线 50 题 Fact Contract 与七组消融需有效模型服务，本次未重跑；旧报告中的 96.0% / 98.0% 不代表本次复测结果。

## 竞赛材料表述

P1–P14 结构保持不变。当前版本的 P12“产品工程”应展示：可信问答及依据抽屉、路线时间表及地图导航、知识库维护，以及两个运行服务。数字人、语音和情感运营不再作为当前交付能力。建议现场顺序：问答并展开证据 → 输入路线需求 → 补齐缺失条件 → 展示可行或不可行结果 → 知识库维护。

既有 PPTX、PDF、Word、录屏、`release/competition_final/` 和历史评分报告保留为历史版本，没有伪装为本次重新生成的交付件。引用这些材料时应明确版本；当前代码的现场演示按本说明执行。原始评测数字与数据文件没有重写。
