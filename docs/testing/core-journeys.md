# Core Browser Journeys

## J01 首页进入问答

打开 `/`，点击“智能问答”，确认进入 `/qa`，页面可输入问题。

## J02 普通文字问答

在 `/qa` 输入一个知识库事实问题，发送后确认出现用户消息、完整回答、模型状态和相关景点。

## J03 流式问答

使用 SSE 请求，确认先收到 session，再收到一个或多个 chunk，最后收到 done；最终回答等于全部 chunk 拼接结果。

## J04 连续追问和历史隔离

在同一 session 先问景点位置再问“它有什么特色”；另开 session 问“它”时不能继承前一 session 的历史。

## J05 语音不可用恢复

模拟浏览器没有 SpeechRecognition 或用户拒绝麦克风，确认文字输入仍可用，页面不永久 Loading。

## J06 图片识别

上传一张已标注景点图片，确认出现识别结果；上传空文件或非法类型时出现可理解错误。

## J07 可行路线

输入当前时间、地点、剩余时长和合理偏好，确认路线有步骤、状态为可执行、时间不超预算。

## J08 不可行路线

输入腿脚不便、三小时、当前 10:00、偏好 14:00 演出，确认状态为不可行或已调整偏好，不能显示空路线可执行。

## J09 附近景点

允许定位时显示附近结果；拒绝定位时显示说明并保留其他首页功能。

## J10 管理员登录和仪表盘

未登录访问管理页面被重定向；正确登录后可见统计、会话列表和筛选控件。

## J11 知识库生命周期

上传测试文档、查看列表、重建索引、执行测试查询、删除文档并再次查询，确认临时知识库状态闭环。

## J12 报告、数字人和导出

读取并保存数字人配置，切换日报/周报/月报，筛选会话并下载 CSV，确认页面均有完成状态或错误状态。
