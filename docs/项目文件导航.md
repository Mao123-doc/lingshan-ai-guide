# 项目文件导航

整理日期：2026-10-03。日常先按用途打开下面的入口。

| 用途 | 位置 | 说明 |
| --- | --- | --- |
| 开发与运行 | [项目说明](../README.md)、`backend/`、`frontend/` | 保持现有启动与构建路径 |
| 事实与评测证据 | `data/`、`evaluation/`、[竞赛技术文档](competition/) | 原始数据、评测结果和事实台账保留原位 |
| 编辑竞赛材料 | [材料包](../竞赛汇报与文档材料包/README.md) | PPT、图片、申报报告、评测报告、演示材料按 01–05 分类 |
| 使用冻结发布包 | [发布包](../release/competition_final/README.md) | 独立交付副本及 SHA256 清单，整理不改其内容 |
| 查看编号材料存档 | [2026-09-25 材料](../release/submission-20260925/) | 原编号目录整体迁入；保留视频、PPT 和 PDF，不推断是否已提交 |
| 查看压缩包存档 | [压缩包](../release/archives/) | 原根目录 7z，未经核对不作为冗余删除 |
| 查看生成输出 | `output/` | 保留独有的 Word、PDF、插图和 LaTeX 输出，不能仅凭目录名当垃圾删除 |
| 查看现场录制 | `recordings/` | 保留录屏与产品截图 |
| 使用维护工具 | [脚本说明](../scripts/README.md) | 常用工具保留根层，一次性材料加工脚本集中存档 |
| 查看软著申请资料 | [软著申请资料](../软件著作权申请资料/正式资料/) | 包含正式代码前/后30页、操作手册、申请表及分析底稿 |
| 查看答辩审查提取 | `evaluation/review_materials/` | 10-06 最新答辩 PPT 与项目方案 2.0 提取文本与结构审核 |
| 查看整理及删除清单 | [本次整理记录](maintenance/2026-10-03-cleanup.md) | 记录迁移、待删除文件与校验结果 |

`docs/superpowers/` 保留历史方案与决策；`.worktrees/`、`.superpowers/` 保留工具状态。现有材料中的指标与历史说法不在本次文件整理中重写，正式引用仍需核对证据台账。

新增交付源文件放材料包对应分类；正式发布通过 `scripts/build_release_package.py` 生成。临时抽帧、提取文本和排版试验放 `tmp/`，不要散落根目录。
